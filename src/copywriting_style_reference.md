# 通用动画口播风格参考

## 1. 写作原则

- 先判断题材，再选择适合该题材的叙述方式。
- 围绕题目本身展开，不主动引入无关领域的术语、比喻或价值判断。
- 故事题材讲清人物、目标、阻碍、转折和结果。
- 知识题材先讲可观察的现象，再解释原因、机制或背景。
- 历史、神话和民俗要区分史实、常见传说与不同版本。
- 科学、技术、医学、财经和法律内容要说明事实依据与适用边界。
- 第一次出现陌生概念时先说人话，再给出正式名称。
- 每行只推进一层信息，句子短而完整，方便口播和动画拆分。
- 先找观众最可能判断错的地方，再解释为什么会错；反常识必须有事实、机制或后果支撑。
- 冲击感来自具体反差和真实代价，不来自“震惊、颠覆、底层逻辑”等词。
- 实用主题至少给出一个具体场景、一条可观察信号和一个可执行动作。
- 动作要写清在什么情况下做、看哪个对象、用什么标准判断。
- 不编造数据、史实、研究结论、人物行为和因果关系。
- 不使用点赞、关注、评论等营销结尾。

## 2. 题材纯度

- 讲神话就使用神话中的人物、法宝、事件和文化背景，不强行映射成程序、芯片或商业模型。
- 讲历史就围绕当时的人物和环境，不用现代网络热词替代关键事实。
- 讲自然和科学就解释真实现象，不为了戏剧效果编造结论。
- 讲技术时可以使用技术术语，但比喻必须回到真实机制。
- 只有用户明确要求跨领域类比时，才把两个领域建立持续映射。

## 3. 参考文案：八仙为什么要各显神通

八仙过海为什么不用同一种法术
因为这句话讲的不是统一行动
而是八位仙人各自亮出法宝
铁拐李有葫芦和铁拐
吕洞宾常以宝剑为标志
何仙姑手持荷花
韩湘子以洞箫闻名
不同版本里的渡海细节并不完全相同
但故事始终保留同一个核心
八个人面对同一片海
各自用最擅长的本领通过
这才有了八仙过海
各显神通

## 4. 参考文案：雨后为什么容易看到彩虹

彩虹为什么总在雨后出现
因为空气里还漂着许多小水滴
阳光进入水滴时会改变方向
不同颜色偏折的角度并不相同
原本混在一起的白光
就这样被分成一圈圈颜色
但只下雨还不够
太阳通常要在观察者身后
水滴则要位于前方
位置合适时
你才会看到那道彩色圆弧

## 5. 参考文案：一个人物故事怎样推进

他先遇到一个具体难题
观众看见难题造成的直接结果
接着揭示人物为什么不能绕开它
第一次尝试带来新的阻碍
关键选择让事件发生转折
结尾交代结果
并回答开头留下的问题

## 6. 不推荐的表达

- 为了显得新奇，把任何人物都比作 CPU、数据库、算法或商业产品。
- 把民间传说写成已经证实的历史事实。
- 用一串并列知识点代替事件推进。
- 开头堆背景和定义，迟迟不进入具体问题。
- 为了制造冲突而虚构具体数字、绝对结论或人物对话。
- 用“随着时代发展”“值得注意的是”“从本质上讲”给正文垫话。
- 连续使用“不是 A 而是 B”“真正关键的是”等模板化转折。
- 只说“保持关注、提升认知、多做分析”，却不给场景、信号和动作。
- 为了显得全面，把一条文案写成多个并列知识点和行业趋势。
