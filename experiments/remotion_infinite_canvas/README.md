# Remotion 无限知识画布实验

该目录是一套完全独立的视觉实验，不修改 `src/` 正式流程，也不改写 `output/` 中的原素材。

第一份样片读取“计算机硬盘的起源与发展”的原图片、旁白和字幕时间，截取前 29.8 秒，重新组织成连续移动的知识地图。

## 视觉语言

- 取消固定标题栏和逐镜头重置布局；
- 白底素材经过实验性透明化后放入一张大型空间画布；
- 镜头在六个知识节点之间连续推拉和移动；
- 路径随旁白现场绘制；
- 数字、年份和关键词成为空间地标；
- 保留原旁白与字幕时间。

## 运行

```bash
cd experiments/remotion_infinite_canvas
npm install
npm run prepare:assets -- --project-dir "<项目目录>"
npm run studio
```

渲染样片：

```bash
npm run render
```

输出文件位于 `out/infinite-canvas.mp4`。

## 接入正式流程

主程序的“视频制作”区域新增“成片方式”下拉框，默认是“剪映草稿（现有流程）”。
选择“无限画布成片（实验）”后，前面的文案、配音、分镜、图片和布局步骤仍然照常执行，
随后进入无限画布专属的细分阶段。它们不是四种模式，而是最终成片前后相连的四个小步骤：

```text
共享 01～06：文案、配音、分镜、图片内容、生图提示词、图片
07 准备素材：把图片、配音和分镜整理成实验项目能读取的文件，产物是 `out/source.json`。
08 规划镜头：决定图片在大画布中的位置，以及推近、拉远、移动和字幕时间，产物是 `public/manifest.json`。
09 生成画面：按规划渲染出一组动画帧，产物是 `out/frames/`，此时还不是 MP4。
10 合成视频：把动画帧和旁白合成为最终 MP4，写入 `output/<主题>/landscape/`。
```

每个 Stage 都可以在界面中单独执行；剪映草稿和剪映导出阶段会自动隐藏。
最终视频仍写入标准路径：

```text
output/<主题>/landscape/<主题>_landscape.mp4
```

因此作品发布页无需知道视频来自剪映还是 Remotion，也不会改变默认的剪映流程。

当前 macOS 低于 15，实验脚本会让 Remotion 只渲染 JPEG 帧序列，再使用系统 `ffmpeg` 编码 H.264 并合入原旁白，完全避开 Remotion 自带 FFmpeg 的系统兼容问题。素材默认保留完整插画卡片，不强制抠透明背景；透明度只在素材本身确实需要叠加时使用。

## 字幕与原始插画

底部字幕读取 `timeline.csv` 中的完整旁白句子，按语义拆分长句并在原句时间范围内按长度分配显示时间。顶部标题读取 `shot_timeline_source_time.csv`，两者分别写入 manifest 的 `captions` 和 `chapters`，不会再用分镜关键词替代字幕。

素材优先读取 `generated_assets_plus/originals/` 中的同名原图，避免继承共享素材目录中已经发生的抠图损伤；没有原图时才使用现有素材。图片保持原始像素和透明度，在固定展示区域完整缩放，不再按白色阈值去背景。

画布保留所有空间节点和路径，只渲染一张持续存在的世界画布。`src/video/camera.ts` 根据素材时间轴连续计算镜头位置和缩放：先拉远到能同时看到前后节点，再沿路径移动，最后推近目标图片。开场展示局部全景，结尾拉远展示全图；网格、节点编号、连接线随同一镜头运动，已经讲过的图片保留在原处。字幕和顶部标题固定在屏幕安全区域。

## 可复用特效库

`effect_catalog.json` 持久保存效果名称和默认时长，`src/video/effects.ts` 保存每种效果的独立实现。规划器和渲染器共用此目录；新增目录项必须同时实现对应动画，TypeScript 会检查覆盖是否完整。

- 8 种转场：横向推移、纵向推移、缩放推进、缩小展开、横向擦除、纵向擦除、圆形展开、弧线旋入。
- 8 种图片入场：向上浮入、左侧滑入、右侧滑入、由小放大、横向揭示、中间展开、轻旋回正、立体翻入。
- 5 种镜头运动：拉远平移、弧线绕行、升降转向、纵深拉镜、全景过渡。保存为节点的 `camera_move` 和 `camera_frames`，与图片特效分别调度。

每张图片分别获得 `transition`、`transition_frames`、`image_animation` 和 `image_animation_frames`，不再对整个分镜共用一个转场。效果按播放顺序确定性洗牌，每轮用完再重复，跨分镜相邻也不重复；第一张图片只有入场，没有前置转场。短镜头会限制动效时长，使原图在下一次切换前恢复完整显示。

8 种原转场在图片内部作为入场特效执行，不再替换整个世界画面；5 种镜头运动负责画布上的真实位置变化。字幕和标题保持稳定，动效结束后图片恢复完整原图。运行 `npm run test:effects` 验证效果起止状态、镜头连续性、转场中点能看到前后节点，以及逐帧检查镜头不会移动到空白区域。

以上调整只作用于本目录的 Remotion 渲染器，原始素材和剪映流程保持独立。

安装为独立剪映预览草稿：

```bash
python3 install_to_jianying.py
```

剪映首页会出现 `实验_Remotion无限画布_硬盘起源`，与正式草稿完全独立。
